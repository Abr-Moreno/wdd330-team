# Trello → GitHub Workflow

1. **Choose a Trello card**

   * Assign yourself to the card.
   * Move the card to **Doing**.

2. **Create a branch**

   * Create and switch to a new Git branch for the work.

3. **Complete the work**

   * Make your changes and test them.

4. **Lint and format**

   * Run the project's lint and formatting commands.

5. **Commit and push**

   * Commit your changes.
   * Push your branch to GitHub.

6. **Move the Trello card to Done**

   * Only move the card to **Done** once your work is complete and pushed.

7. **Create a Pull Request**

   * Create a PR from your branch into `main`.

8. **Notify the team**

   * Let your group know that a Pull Request is ready for review.

9. **Review and merge**

   * Another team member reviews the Pull Request in GitHub.
   * If everything looks good, they merge the Pull Request.
   * After merging, delete the old branch.
